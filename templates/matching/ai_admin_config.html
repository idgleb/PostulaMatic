Guía de Configuración
OpenAI
  1. Ve a OpenAI API Keys
  2. Crea una nueva API key
  3. Copia la clave que empieza con sk-
  4. Pégala en el campo "API Key" de arriba
Anthropic
  1. Ve a Anthropic Console
  2. Crea una nueva API key
  3. Copia la clave que empieza con sk-ant-
  4. Pégala en el campo "API Key" de arriba
Nota: Las API keys se configuran en variables de entorno del servidor. Contacta al administrador para configurarlas.
Importante: Las API keys se almacenan encriptadas en la base de datos. Asegúrate de tener backup de tus claves originales.
